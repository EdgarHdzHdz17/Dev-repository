# Actividad: primeros pasos con Git y GitHub

**Objetivo:** practicar el flujo diario en `main`: ver cambios, guardar archivos, crear commits y subirlos a GitHub.

**Archivos de trabajo:**

- `Nombre.md`
- `NombreV2.md`
- `Apellido.md`

---

## Antes de empezar

Abre la terminal en la carpeta del repositorio y confirma que estás en `main`:

```bash
git status
git branch
```

Debes ver `On branch main`.

---

## Parte 1 — Ver el estado del repositorio

1. Ejecuta:

```bash
git status
```
